EventSphere AI - MVP Overview

MVP Document · Product specification

Project Overview

EventSphere AI is an AI-powered event planning and vendor marketplace platform. It bridges the gap between people organizing events (Customers) and event service providers (Teams/Vendors). The platform automates budget breakdowns and packages while providing an extensive CRM for vendors.

Core Features

  • AI Event Generation: Generates standard, premium, and luxury service packages using a Hugging Face LLM based on user inputs.
  • Micro-Transaction Paywalls: A lead-generation model where customers pay a small fee via Razorpay to unlock vendor contacts.
  • Vendor Operations (CRM): A comprehensive dashboard with a Kanban board to track leads and an inventory manager for services.
  • Role-Based Routing: Strict separation of the app into /customer/ and /vendor/ routes.
