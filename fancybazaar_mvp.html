FancyBazaar - MVP Overview

Project Overview

FancyBazaar is a modern, full-stack e-commerce platform built to support both standard retail customers (B2C) and wholesale buyers/vendors (B2B). The MVP allows users to browse products by categories, manage a shopping cart and wishlist, view vendor-specific shops, and securely checkout. It includes a vendor dashboard for merchants to manage their inventory and an admin panel for overall platform management.

Core Features

  • Dual Marketplace: Supports both B2C retail and B2B wholesale transactions seamlessly.
  • Vendor Dashboards: Dedicated interfaces for merchants to manage inventory, update stock, and control their specific shops.
  • Product Browsing: Categorized product viewing, wishlist management, and smart cart integration.
  • Secure Checkout: Encrypted transactions and order tracking.
  • Admin Panel: Overall platform administration, user role management, and system monitoring.
