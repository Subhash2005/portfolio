CA Companion - MVP Overview

MVP Document · Product specification

Project Overview

The MVP is an AI-powered mobile application designed for Chartered Accountants (CAs). It allows users to upload documents (invoices, tax forms, etc.) and uses artificial intelligence to analyze them, extract relevant financial data, and provide summaries.

Core Features

  • Intelligent Document Analysis: Upload invoices or tax forms directly from the mobile device for AI evaluation.
  • Data Extraction: Automatically extract key financial metrics, health scores, and margins.
  • Secure Client-Server Communication: Converts files to Base64 to securely transmit to Vercel Serverless Functions before querying Google Gemini.
  • Enterprise-Grade Security: Hides API keys on the server to prevent exposure within the mobile app codebase.
