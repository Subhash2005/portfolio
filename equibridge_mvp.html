EquiBridge - MVP Overview

MVP Document · Product specification

Project Overview

EquiBridge is a full-stack web application designed to connect different demographics—students, daily workers, and individuals with disabilities—to opportunities, resources, and work. It features specialized portals tailored to the unique needs of each user group, alongside accessibility features like a voice-navigated assistant and built-in translation.

Core Features

  • Student Portal: For finding organizations, tracking progress, viewing job statuses, and managing a "Dream Pipeline".
  • Daily Work Sector: Geared towards daily wage workers to find nearby work, track revenue, manage investments, and access emergency funds.
  • Disability Sector: An accessible portal for users with disabilities to find inclusive job vacancies.
  • Voice Assistant: Hands-free navigation utilizing the browser's Web Speech API.
  • Auto-Translate: Google Translate integration to dynamically translate the UI into the user's native language.
