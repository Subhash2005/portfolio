ThinkLearn AI - MVP Overview

Project Overview

ThinkLearn AI is an advanced Concept Learning Tutor that flips the traditional AI chatbot paradigm. Instead of acting as an "answer machine" that hands out immediate solutions, it acts as a mentor. Its primary goal is to help users THINK, REASON, and DISCOVER answers themselves. It achieves this by assessing user knowledge levels, breaking complex concepts into manageable chunks, and using a Socratic teaching style that heavily relies on guided questioning and hints.

Core Features

  • Assess Prior Knowledge: Always gauges where the user stands before introducing new information.
  • Socratic Learning: Asks guiding questions ("Why do you think that?", "What if this condition changed?") before giving explanations.
  • Adaptive Difficulty: Automatically adjusts the complexity of examples based on whether the user is struggling or succeeding.
  • Progressive 3-Tier Hint System: Gradually reveals clues (Level 1, Level 2, Level 3) instead of jumping straight to the solution.
  • Daily Revision AI: If a user returns the next day, the system recalls the previous session summary and tests retention before moving on.
  • Curiosity Mode: Promotes exploration by constantly prompting the user with "Why?", "How?", and "Can you predict?".
