MedHelp : Medicinal help agent

1. Terminology & Core Concepts

  • Multimodal Vision AI: An AI capable of processing both text and raw images simultaneously to understand context (e.g., reading a handwritten prescription and understanding the medicine's chemical purpose).
  • Zero-Shot OCR Translation: Bypassing traditional Optical Character Recognition (OCR) step-by-step processing. The AI looks at the image and directly translates messy handwriting into another language (like Tamil or Hindi) without needing a middle-man text file.
  • Smart Triage Engine: An automated system that ranks a user's symptoms by urgency (Low, Medium, High, Emergency) before giving advice.
  • Polypharmacy Cross-Referencing: (The Pillbox feature). The algorithmic checking of multiple overlapping drug mechanisms to detect severe chemical interactions.

2. Tech Stack & Frameworks

Languages & Environments

  • JavaScript (ES6+): The primary programming language used for all logic, API interfacing, and UI rendering.
  • Node.js Environment: Powers the Expo Metro bundler and package management.

Frameworks & Kits

  • React Native: The core mobile app framework used to build native Android and iOS interfaces from a single codebase.
  • Expo Framework: The overarching toolchain used to compile, test, and deploy the React Native app. Specifically, EAS (Expo Application Services) was used for cloud-compiling the Android .apk.
  • React Navigation (@react-navigation/native): Handles the complex Native Stack routing between the Home, Chatbot, Pillbox, and Scanner screens.

AI & External Tools

  • Google Gemini 2.5 Flash API: The state-of-the-art LLM used for all intelligent features. Chosen for its extreme speed and native image-processing capabilities.
  • @google/generative-ai SDK: The official toolkit used to communicate directly with Google's servers.
  • expo-image-picker: The native module kit used to access the user's local smartphone camera hardware and photo gallery securely.

3. The MVP Feature Set

  • Intelligent Scanner: Snap a photo of a messy prescription or unknown pill to get plain-text instructions and identification.
  • Native Translation: Instantly converts medical jargon into English, Tamil, Hindi, or Spanish.
  • Generics & Cost-Saver: Suggests cheaper chemical equivalents for expensive branded drugs.
  • Interaction Pillbox: A virtual safety net that warns users if mixing their current medications is dangerous.
  • Role-Based Medical Database: Explains drugs differently depending on if the user is a normal patient, a pharmacology student, or a doctor.
