Make Me Fit - MVP Overview

MVP Overview

"Make Me Fit" is a health and fitness tracking application designed to help users manage their lifestyle, diet, and routines. The MVP includes features like user authentication, a customizable dashboard, food and workout journaling, meal swapping, a grocery list generator, an AI or human coach interaction interface, and a barcode/food scanner. It utilizes a cross-platform mobile app frontend backed by a robust Node.js backend.

Important Terminology

  • Journal: A daily log where users track their meals, workouts, and possibly water intake or habits.
  • Meal Swap: The ability for users to replace a suggested or logged meal with an alternative based on dietary preferences or calories.
  • Scanner: A barcode or image recognition tool to quickly input food nutritional data into the journal.
  • Coach: A module (could be AI-driven or connecting to human trainers) providing personalized fitness and diet advice.
  • Grocery List: An auto-generated list of ingredients needed based on the user's planned meals for the week.

Main Concepts

  • Holistic Tracking: Combining meal planning, grocery shopping, and workout logging in a single interface.
  • Personalization: Using profile data and onboarding preferences to tailor dashboard metrics and meal suggestions.
  • Frictionless Entry: Utilizing a scanner to reduce the manual effort of logging food items.
  • Actionable Insights: Presenting data using charts (via fl_chart) and progress indicators (percent_indicator) to help users visualize their fitness journey.

Important Frameworks & Tools

Frontend (Mobile App)

  • Framework: Flutter (Dart) - Allows a single codebase for Android and iOS.
  • State Management: Provider - A robust and scalable way to manage application state across screens.
  • UI Components: fl_chart & percent_indicator for data visualization, google_fonts, cupertino_icons.
  • Utilities: image_picker, path_provider, pdf, printing, http.

Backend (API Services)

  • Runtime & Framework: Node.js with Express.js - Fast web framework for building RESTful APIs.
  • Database Modeler: Mongoose - Elegant MongoDB object modeling for Node.js.
  • External Services: Firebase Admin SDK - Used for robust authentication, push notifications, or file storage.
  • Environment: dotenv for configuration and cors for cross-origin resource sharing.

Models (Data Structures)

  • User / Profile: Stores credentials, demographics, goals, and preferences.
  • Journal Entry: Represents daily logs (MealEntry, WorkoutEntry).
  • Food Item: Contains macronutrients, calories, and barcode data.
  • Grocery List: An aggregated collection of ingredients derived from planned meals.
  • Coach Session/Message: Logs of communication or AI prompts regarding user guidance.

Architecture Used

  • Frontend Architecture (Flutter): Screen-Based Routing, Main Tab Navigation, Provider Pattern.
  • Backend Architecture (Node.js): RESTful API, NoSQL Database (MongoDB), Integration Layer (Firebase Admin).
